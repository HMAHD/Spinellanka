### 1. Consolidated Findings & Resolutions

| ID | Severity | Domain | Consolidated Finding | Resolution in Final Specification |
|---|---|---|---|---|
| **RES-01** | Blocker | Configuration Transfer & FK History | `PricingRule` has no `external_key` column; `PricingRuleService::updateRule()` unconditionally increments `version`, breaking repeat-import idempotency and mutating historical `Estimate` snapshots. | Store deterministic `config_key` inside `pricing_rules.metadata`. Skip identical rules on import (zero `version` bump). On drift, call `deactivateRule()` + `createRule()` so historical `Estimate` / `EstimateItem` FKs stay immutable. |
| **RES-02** | Blocker | Vehicle 5-Row Invariant & Rollback | `VehicleService::updateVehicle(..., ['status' => Retired])` irreversibly closes open `VehicleDriverAssignment` rows; sequential plate swaps collide on `UNIQUE(license_plate)`; `export()` without filtering `Retired` can exceed 5 rows. | Export/enforce 5 non-retired vehicles (`Active` / `Maintenance`). Perform 2-pass temporary plate swap inside transaction when swapping plates. Reject retiring vehicles with active bookings/assignments during config sync; reconcile `RentPolicy` via dedicated `RentPolicyService`, `ExchangeRateBasis` via `now('Asia/Colombo')` on rollback, and deactivate (never hard-delete) `VehicleMedia` to avoid triggering disk unlink inside `booted()`. |
| **RES-03** | Blocker | Checksum Canonicalization & Concurrency | Empty `{}` (`operational_policies`) decodes as `[]`, altering SHA-256 on round-trip; `DB::transaction()` defaults to `REPEATABLE READ`; pre-Phase-16 DB baseline lacks `approval_metadata`. | Remove `operational_policies` (since `config/booking.php` is static/cached on cPanel). Canonicalize typed arrays/nulls with `ksort` on associative arrays only, `Asia/Colombo` ISO-8601 dates, and `JSON_PRESERVE_ZERO_FRACTION | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE`. Store exact `payload_json` and compute checksum over `['schema_version', 'package_classification', 'record_counts', 'payload']`. Guard `import()`/`rollback()` with `Cache::lock` + `lockForUpdate()`, and exempt tagged pre-Phase-16 baselines from `approval_metadata` enforcement on rollback. |
| **RES-04** | Blocker | Secret/PII Filtering & Production Guard | Substring value scanning rejects valid English words (`"whatsapp"`, `"email"`); `"exported_by"` exports staff email; `vin`/`registration_expiry`/`insurance_expiry` were unexcluded; `staging_synthetic` lacked runtime production guard. | Replace `"exported_by"` email with non-PII `"exported_by_role"`. Scan **keys** recursively inside `payload` (reusing/extending `AuditService` sensitive-key list + PII keys + `vin`/`registration_expiry`/`insurance_expiry`), and scan string **values** only for credential/PII patterns (API key prefixes, Bearer tokens, DSNs, raw email/E.164 phone regexes). Validate inside `export()` as well as `import()`, store `approval_manifest` in package/snapshot, and fail closed publicly if `app()->isProduction()` encounters `staging_synthetic` snapshots or `SYNTH-VEH-` vehicles. |
| **RES-05** | Blocker | Google Maps Quota, `getDetails()`, & Degradation | `AirportPickupBookingController::create()` and `AirportTransferBookingController::create()` call `placeSearchService->search()` on every GET render; `getDetails()` was omitted; `place_id` validation `max:64` is too short for Google Place IDs; fallback to Haversine underestimates mountain travel times; `Referer` header is wrong for server REST calls; timeouts conflicted (`3s/8s` vs `5s`). | Implement both `search()` and `getDetails()` in `GoogleMapsPlaceSearchService` with `X-Goog-Api-Key`, `X-Goog-FieldMask`, `regionCode=LK`, `connectTimeout(3)->timeout(5)`, PII stripping, and DB caching (`24h` for static airport/hotel lookups, `15m` for queries). Raise `place_id` validation to `max:255`. Return `null` from `GoogleMapsRouteEstimateService` on API failure (triggering custom-quote / route-unavailable notice rather than Haversine); delegate missing-key mode to `Null*` services. |
| **RES-06** | Blocker | Plausible Analytics Isolation & CSP | Denylist misses `booking.documents.download` and 404 views extending `layouts/app.blade.php`; inline `<script>` breaks strict CSP; footer button was missing from `layouts/app.blade.php`. | Replace denylist with explicit **positive route allowlist** (`home`, `services.*`, `fleet.*`, `how-it-works`, `help`, `contact`, `legal.*`) plus `$request->route() !== null`. Bundle consent & script loader in Vite-compiled `resources/js/app.js` (zero inline `<script>`), place `"Analytics settings"` control in `partials/footer.blade.php`, and load Plausible with `async defer fetchpriority="low"` only after explicit consent. |
| **RES-07** | Major | YAGNI Simplification (`ErrorReporter`, `OffHostBackupContract`, `SnapshotStatus`) | Bespoke `ErrorReporter` and `OffHostBackupContract` interfaces duplicate Laravel `report()`/`bootstrap/app.php` and `Storage::disk()`; 4-state `SnapshotStatus` (`staged`, `rolled_back`) adds unused state complexity. | Simplify `configuration_snapshots` to `is_active` + `rolled_back_from_id` + `AuditService`. Scrub PII/tokens/coordinates directly in `bootstrap/app.php` (`$exceptions->reportable` / Sentry helper gated on `services.sentry.dsn`, no new Composer packages). Replace `OffHostBackupContract` with `backup:verify` Artisan command checking `proc_open`, `--defaults-extra-file` (`0600` temp file cleaned in `finally`), SHA-256 manifest, and `filesystems.disks.off_host_backup` readiness. |
| **RES-08** | Major | Filament Re-Auth & Artisan CLI Contracts | `RequiresReauthentication` trait already exists in `app/Filament/Concerns/`; CLI commands lacked explicit `--apply`/`--dry-run` defaults, `--actor`, and `--force` flags. | Reuse `RequiresReauthentication::configureReauthentication()` on Filament rollback action. Default `config:import-package` to `--dry-run` unless `--apply` is explicitly passed; accept `--actor`, `--notes`, `--force`, and deterministic exit codes (`0` success, `1` validation/security failure). |
| **RES-09** | Major | `CHG-003` & Synthetic Driver Constraints | `CHG-003` was pending in `08-acceptance-and-signoff.md`; `drivers.full_name` and `drivers.phone` are NOT NULL in DB. | Record `CHG-003` in `docs/ux/08-acceptance-and-signoff.md` with Project Lead approval (2026-11-27). Populate synthetic `StagingSyntheticFixturesSeeder` drivers with explicitly synthetic non-PII values (`SYNTH-DRIVER-01`, `+94000000001`), while excluding driver PII from configuration exports. |
